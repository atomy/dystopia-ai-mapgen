# dys_blackice generator

Source for **dys_blackice** ("Black ICE"), a Dystopia objective map. The whole map is generated by these
Python scripts: geometry, gameplay logic, cyberspace, dressing, 3D skybox, custom textures and release extras.
The scripts then compile it with Dystopia's own tools and test it in-game automatically.

See [PLAN.md](PLAN.md) for the design and status, [SESSION_MEMORY.md](SESSION_MEMORY.md) for verified
Dystopia facts and lessons from the build session, and [README_release.txt](README_release.txt) for the
player-facing readme that ships with the map.

## Requirements
- Dystopia installed at `M:\SteamLibrary\steamapps\common\Dystopia` (paths live in `tools.py` and `assets.py`)
- Source SDK Base 2013 Multiplayer, used only for `bspzip.exe`
- Python 3.12 + Pillow; Steam running for in-game tests
- Blender 5.x, only to rebuild the monument model (`python monument.py`)

## Build
```
python blackice.py --compile --final                      # generate, validate, compile, pack
python -c "import tools; tools.build_cubemaps('dys_blackice')"
python release.py qa | logic | shots | loading | zip        # QA and release steps
```
`python blackice.py` alone only generates and validates `maps/dys_blackice.vmf`. `--compile` without
`--final` does a fast vis/rad pass. Output goes to `dystopia/maps/`. Logs, screenshots and release zips go to
`build/`, which is git-ignored.

## Modules
| File | Role |
|---|---|
| `vmflib.py` | VMF writer: brushes, texture axes, entities, I/O, overlays |
| `csg.py` | Box-CSG shell: paint solid/air boxes, get sealed world brushes (leak check, texture bands) |
| `look.py` | Per-zone material recipes + the CSG face resolver |
| `blackice.py` | The level: shell layout, stairs, build orchestration, cubemap placement, packing |
| `gameplay.py` | Spawns, objectives, gate/hub/core logic, forcefields, turrets, jack-in terminals, screen panels |
| `cyberspace.py` | Cyberspace hall: core terrace, entry pads, terminal houses whose doors are the ICE |
| `dress.py`, `dress_in.py`, `dress_polish.py` | Street, plaza, interiors, lighting, props, signage, weather |
| `sky3d.py` | 3D skybox megacity skyline |
| `monument.py`, `monument/` | Kuroda monument prop: Blender build script, SMD exporter, textures, QC (see monument/README.md) |
| `custom_art.py` | Custom textures (Pillow -> vtex) |
| `extras.py` | Radar overview, mappaths, soundscapes, music, loading screen |
| `panels.py` | dys_screen / dys_cyberscreen VGUI panels |
| `kit.py` | Detail kit: stairs, doors, glass, rails, props, lights |
| `validate.py` | Pre-compile checks: I/O targets, assets, translucency, entity placement |
| `tools.py` | Compile, bspzip pack, in-game automation (`GameSession`, tours, walk tests, cubemaps) |
| `assets.py` | VMT/VTF/MDL readers, contact sheets |
| `release.py` | Clean-client QA, logic regression, beauty shots, loading screen, release zip |
